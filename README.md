# 199 AI 错题本

面向 199 管理类联考的错题整理与学习平台：拍照或上传题目图片、OCR 识别与校对、记录错因、AI 提示和讲解，以及重做检验。

线上入口：https://exam199.transistorsandtokens.com/

## 功能（数学冲刺版）

- **题型精讲（核心）**：代数 6 章 42 个题型。每个题型有一条「思考路线」（拿到题按顺序问自己的 3–5 个问题）、要套的公式、识别信号、秒杀与易错，2 道带"思路拆解"的例题，6 道分级练习（基础 1 / 真题难度 3 / 拔高 2，每道有"给点思路"提示）。「卡住了」按题目关键词搜索对应题型；练习做错可一键加入错题本。
  - 内容在 `server/content/topics/`（每章一个文件，含 LaTeX 的字符串用 ``r`...` ``）
  - `node scripts/lint-topics.mjs`：检查格式、公式反斜杠、选项与答案分布
  - `python scripts/verify-topics.py`（需 sympy）：逐题重算答案，并核对答案字母对应的选项
- **今日任务**：首页汇总到期错题、公式卡、待整理题目、薄弱知识点，以及考试倒计时和连续学习天数。
- **录题**：拍照/粘贴/多图，OCR 识别后校对（带公式预览）；也可以"只存图片，稍后整理"。
- **知识点**：内置 199 数学知识点树（`server/content/math.js`），录题时点选，首页按知识点统计薄弱项。
- **间隔复习**：新题默认第二天进入复习；限时重做后自动排期（答对 1→2→4→7→15→30 天，答错明天再来），连续答对 3 次标记为已掌握。
- **条件充分性判断**：重做时分三步判断（条件(1)单独、条件(2)单独、联合），自动换算成 A–E 选项，并指出错在哪一步。
- **公式卡**：53 张内置公式/技巧卡片，按"忘了/模糊/记得"间隔复习，每天最多引入 12 张新卡。
- **AI 老师**：三级渐进提示（考点 → 切入点 → 解题路径），完整讲解含"快速解法"；公式由 KaTeX 渲染。

## 本地运行

```bash
npm install
cp .env.example .env
# 在本机填写 .env，再启动
npm start
```

前端是 `public/` 下的静态文件，无需额外构建。生产环境通过 `ecosystem.config.cjs` 使用 PM2 启动，默认监听 `127.0.0.1:3005`，由 Nginx 提供公网 HTTPS 入口。

## 配置与数据

- `.env.example` 提供配置模板；真实 `.env` 不提交。生产环境须设置随机 `JWT_SECRET` 与注册 `INVITE_CODE`。
- OCR 使用服务端 `GLM_API_KEY`。AI 老师配置方式见 `.env.example`；不向前端暴露密钥。
- `data/` 保存数据库，`uploads/` 保存题目图片，`logs/` 保存运行日志；这些目录均排除在 Git 之外。
- GitHub 只用于保存代码。更新服务器时保留原有 `.env`、数据库和上传文件。

## 目录

- `server/`：后端接口、账号、数据库和模型调用；`server/content/` 为知识点树与公式卡内容。
- `public/`：网页界面与样式。
- `docs/EXAM-199-INFO.md`：考试与功能参考资料。
- `TASK.md`：原始项目任务书；`DESIGN.md`：代码 review 与数学学习平台设计。
- `deploy/backup.sh`：现有服务器备份脚本，运行前核对其中的部署路径。

此仓库在已有任务书提交的基础上同步阿里云 `Exam199-Study` 源码，不包含账号数据、错题、图片或真实密钥。
